# HMI认帽与拧松工步独立控制接入 v0.7

本版扩展场景9的HMI模式3解码及功能参考控制器，独立接头`feedback_model.c`保持原样：固定360°座面、阻力/刚度/制动常量，不读取工艺目标，不增加为成功样例定制的夹具。不是实际套筒、电机或FPGA算法，不证明实体紧固质量、工具精度或安全等级。旧原生模式2认帽/OUTPUT仍不冒充已支持；HMI类型1/5不等于旧原生WAIT4/卸荷5。

认帽按§5.3四槽和DC-08接入：停止扭矩、每次旋转角度、重复间隔、1–15次；支持CW/CCW及两种交替起始方向。每次角度到达先按同一接头模型制动至零，再计算间隔和下一次方向；达到真实量化扭矩才认成功。次数耗尽未达扭矩则NOK、停止后续工步；不是次数到即OK。低力上限按客户§7.1的停止扭矩1.2倍作为模型保护，优先于目标；通用超时和失败动作必须为认帽定义的0，保留槽非0拒绝。输入角度受既有INT32位置范围保护，不环绕补值。

拧松工步按§5.3十槽接入，内部kind7与原生OUTPUT6/卸荷5分离。角度策略按门槛后的实际相对角度停止；扭矩策略须先观察到至少目标110%的负载，再下降到目标以下才进入制动，初始低扭矩不等于已松脱。110%回差为本功能参考控制器明确采用的行业实现口径，参考[Atlas Copco Loosen to Torque](https://picontent.atlascopco.com/cont/external/dir/33/12952274827__html5_external/en-US/print-section.html?section=885073012312873619851)，不宣称客户真实FPGA已定义同一算法。两种策略均先检查安全扭矩/安全角度和窗口上限，停稳后复核扭矩/角度窗口；超时保留NOK。CW/CCW指令按原值执行，不能替错误方向伪造反向反馈。工步间不重置接头，测试有载松脱应先真实模拟拧紧，再拧松和复拧。

未改变现有下旋、拧紧、卸荷与WAIT的控制语义。新状态只在认帽/拧松控制器内使用，不进入PDO/SDO，不更改单位或型号对象；`SIM-QNC30`仍标为模拟来源。独立反转结果0x4305、UIO手动/锁定等能力没有因此实现，不能由PSET拧松工步反推那些能力已可用。

新增`tests/test_engage_loosen.c`覆盖真实模式3字节、认帽成功/次数耗尽/交替/停机/联锁/高速保护、两种有载拧松、无载超时、保留槽/非法值拒绝及相同指令下改目标不改接头反馈。宿主完整门禁33个C运行（原29+新增4）及既有位置/SDO计数/映射/字段/刷写边界均通过，ASan/UBSan与断言生效。首轮新测试误用1000rpm验证legacy配置的过冲，legacy按500rpm上限正确拒收；改用两种宽度均合法的300rpm，仍应保护NOK，未放宽接入上限。原失败日志保留在内部证据中。
