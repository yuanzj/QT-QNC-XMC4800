# 故障提前与同拍结束对照验证

版本：v0.1，2026-10-30。本次用于定位可靠结果事件的故障归因边界，不代表真实FPGA故障算法。

场景4保持原行为：运行100ms后，在同一逻辑拍将测试故障0x7001、失败结果与结束步号一起输出。新增编译场景6先在活动工步输出同一测试码20ms，再产生相同的失败结束边沿。两者使用相同PSET和实际SDO/PDO路径，未修改UIO。

| 场景 | 实板次数 | 连续过程流 | 可靠工步/循环事件 |
|---|---:|---|---|
| 正常前置对照 | 3 | 无测试故障 | 正常结果、归因码0 |
| 4：故障与结束同拍 | 3 | 结束步号0时有0x7001 | 失败结果，但归因码均0 |
| 6：故障提前20ms | 3 | 每次20个活动步样本含0x7001，结束后仍保持 | 失败结果，归因码均0x7001 |
| 恢复原正常镜像 | 3 | 无测试故障 | 正常结果、归因码0 |

HMI在两种故障时序下均忠实保存收到的可靠事件。对照将遗漏定位到UIO结束边界的采集/收口路径；不通过修改默认模拟时序掩盖遗漏。0x7001只是未收录故障码测试值，不指定客户生产故障含义。

新增`tests/test_fault_timing.c`直接驱动实际模拟适配入口，检查99/100/119/120ms相对边界、活动/结束步号、结果和复位清错。正常、同拍、提前三种适配测试及六种程序场景检查均通过；两种新增构建均成功，保留原有USB库packed属性和未使用变量警告。

当前源码用原ARM GCC配方构建场景0，HEX与本次修改前同配方制品逐字节一致。实板最终恢复既有DAVE正常镜像，完整2MiB读回与本次首个故障刷写前的备份逐字节一致，SII与扇区空洞保持；该镜像对应原DAVE源快照，断点调试仍应使用其配套ELF和构建快照。新增场景6本轮由命令行编译并实跑，未重新签认DAVE界面调试。

客户可集中查看`FpgaSim/fpga_program.c/.h`、`Simulation/ethercat_adapter.c`、构建场景参数与新增测试。现场抓包、数据库、探针信息和刷写备份不入本仓库。
