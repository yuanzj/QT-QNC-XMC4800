# 位置协议故障向量与默认镜像保全

本入口为TC-HIL-MAP-04的明确协议测试输入，默认关闭，不是客户FPGA算法，也不代表物理编码器或紧固质量验证。

构建参数`--position-test-vector`：

| 参数 | 发布位置的构造 | 用途 |
|---|---|---|
| off（默认） | 模型原位置 | 正常对照 |
| forward-wrap | INT32_MAX−262144＋模型原位置，按32位补码解释 | 同一步正端回绕到负端 |
| reverse-wrap | INT32_MIN＋262144−模型原位置，按32位补码解释 | 同一步负端回绕到正端 |
| step-reset | 奇数步INT32_MAX−536870912＋原位置，偶数步INT32_MIN＋536870912＋原位置 | 跨步大跳变对照，实际输入须核对步内没有回绕 |

step_echo=0不加偏置。所有算术先在UINT32中完成，再安全解释为INT32，无有符号溢出。保持场景9独立接头、INT64/44B和SIM型号；工具拒绝与旧映射或错误长度叠加。只改对象字典发布的位置，不改模型内部反馈、扭矩、速度、状态、启停、质量判定或参数窗口。RAM追踪保留模型原位置。

因此故障位置与模型/工步判定故意不具有物理一致性。负例终态OK不等于紧固质量可放行；位置/事件不一致的其他诊断须如实保留，不能为测试通过修改质量或位置。

主机入口`python3 tools/test_position_fault_vectors.py --output <新目录>`逐拍比较四种实际适配构建，每种6000拍；除位置外输出相同，并检查实际回绕、无回绕对照及非法组合。已纳入总回归入口。首版夹具重复第二步步号导致拒绝的原件保留，纠正为递增步号后通过，未改变控制器判定。
