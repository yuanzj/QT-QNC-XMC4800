# 终态采样工步归属修复

日期：2026-11-06。真实HMI板、真实UIO及XMC4800串联，工具端为本工程场景9独立合成硬接头。UIO源码与固件未修改。

## 原因与修改

原适配层在模型进入DONE或FAULT的同一拍立即清除工步号。高速保护触发样本的实际扭矩为486原始单位（14.58 Nm），但该样本stepEcho已经为0，UIO以此前426（12.78 Nm）的活动工步样本生成工步结果。原始TCP抓包可重复观察；HMI如实保存UIO事件，没有自行更换数值。

`Simulation/ethercat_adapter.c`仅对场景9在RUNNING进入DONE／FAULT时，将真实终态反馈先带原工步号发布一拍，下一拍才清零。保护码、结果、接头反馈、制动过程、目标和窗口均不更改。STOP／RESET仍立即执行，不延迟停止请求。该修改只修正既有模拟边界的样本归属，不代表真实驱动安全效能或精度认证。

## 软件验证

新增`tests/test_terminal_sample.c`覆盖高速保护的越限反馈及工步号、下一拍清零、正常完成和STOP。使用修复前构建快照的适配代码运行时，终态工步归属断言失败；修复后在legacy及INT64两配置通过。全套入口`tools/test_model_profiles.py`共29个C运行、4组实际PDO映射、SDO回调及刷写边界验证通过（断言、ASan／UBSan启用）。

## 实板与范围

本次候选为场景9／hard／int64，Rx12B／Tx44B，速度对象0x2212，模拟型号SIM-QNC30。使用真实HMI正常接口下发、选择，并调用实际监控页面按钮处理器启动；未使用UIO HTTP诊断执行代替正式路径。构建、完整Flash备份、SII保留、全片回读和串联复测详见文档仓`03-计划与商务/真实HMI三板续测_20261106/`。仅源码验证不得代签实板关闭。

既有不支持项仍按v0.6说明明确拒绝，包括启动扭矩非零等。首轮原PSET-001因超出本模型支持范围失败，原工艺及失败记录保留；另建范围内工艺验证首颗，不把原默认工艺签通过。周期时间戳存在2～3ms跳变的观察单列待定位，不能以序号连续代签严格1kHz采样。
