## 四、运行入口

从QT-QNC-XMC4800根目录执行；输出目录必须不存在：

```sh
python3 tools/test_c20_profile.py --cc clang --uio-root ../qtuio --output evidence/c21-new-host-run
python3 tools/test_model_profiles.py --cc clang --output evidence/c21-new-legacy-run
python3 tools/build.py --gcc '<ARM-GCC>/bin/arm-none-eabi-gcc' --output build/c21-new-build --protocol qiaotian-20261116
python3 tools/build.py --gcc '<ARM-GCC>/bin/arm-none-eabi-gcc' --output build/legacy-new-build --protocol legacy
```

测试工具不向UIO目录写入制品，UIO上游源文件只读参与编译。新配套的命令行默认项已更新；DAVE工程仍为历史配置，未签认DAVE新配套构建。所有制品留在本机，没有调用刷板工具。
