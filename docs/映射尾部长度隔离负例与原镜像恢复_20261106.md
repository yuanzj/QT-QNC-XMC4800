# 映射尾部长度隔离负例与原镜像恢复

为TC-HIL-MAP-05新增显式`--negative-pdo-tail`构建选项。仅允许scenario9、INT64及simulation型号，其他组合在创建输出目录前拒绝，避免旧36B向量同时改变速度/身份而混淆因果。该选项只用于负例，不作为正常运行或拧紧质量固件。

启用时0x1A00有效条目13→11，TxPDO44→36B，仅去掉最后两个32位填充；前32B所有真实字段、64位速度/型号对象、原接头控制和判定均保持。实际拷贝循环按所声明长度截止，不写超缓冲；默认关闭仍为13条/44B。不增加协议版本或将36B冒称正常map4兼容布局。

29项模型运行、5组实际映射和原SDO/型号/刷写边界回归通过；INT64负例保留所有原始极值与字段偏移，缓冲哨兵/ASan/UBSan验证无越界，非法场景/未知型号组合均拒绝且不创建产物。

实板负例使用scenario9/hard/int64/模拟型号，独立反馈与native工艺/型号源码10文件SHA保持。临时镜像全片备份、保SII和回读一致后运行；UIO未就绪、HMI拒启/拒切换、无过程数据。未见规定的专用映射错误事件，诊断子项由项目报告单列失败，不因保护有效签全通过。UIO代码/固件未改。

取证后以先前已验证的完整应用扇区镜像恢复，先校验芯片、当前负例全片及源摘要，写入范围不含SII，恢复全片逐字节匹配原镜像再运行CPU；不只核对有效HEX字节而忽略空洞。正式重下发原工艺并回读，正常复跑通过，负例没有留在板端。
