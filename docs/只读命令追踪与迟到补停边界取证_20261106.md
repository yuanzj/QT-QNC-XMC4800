# 只读命令追踪与迟到补停边界取证

2026-11-06。为区分通信受理与模型实际开始，适配层增加RAM只读诊断，控制、反馈、窗口和判定保持原逻辑。没有新增PDO/SDO对象或改变12B Rx/44B Tx、INT64速度、hard独立接头及型号声明。

`Simulation_ControlDiagnostics`保存QNCT/version1、32条环形命令记录、已消费START/STOP/RESET计数与RUNNING拍数。每条含MCU单调毫秒（非墙钟）、命令、许可、任务状态、PSET、处理前后模型状态、实际输出工步/反馈；整条写完才更新总sequence。诊断只读已有模型/输出，不作为任何控制或质量输入。只在空闲时读RAM，前后sequence变化则重读；地址和尺寸从本次ELF符号导出，不能固定套用其他构建。

模型状态0 idle/1 ready/2 running/3 done/4 stopped/5 fault。正常启动应消费一次START并进入running；运行中补停应消费STOP并进入stopped。若已受理的启动在模型消费前取消，模型只消费STOP，START与RUNNING拍数不增加，不应为了生成结果去延迟停止或强制启动。

宿主原29项C运行、映射/SDO/身份和刷写边界检查通过，终态采样用例同时验证legacy/INT64下同拍未消费START不记运行，以及32条追踪环形回卷。实际构建`hil-20261106-control-trace-hard-int64`为scenario9/hard/int64；全片备份、SII/扇区空洞保全及回读通过。证据在本工程`evidence/hil-20261106-control-trace-*`，现场逐循环记录在项目测试文档中，不把模拟反馈当物理工具精度证明。

实测六次迟到启动：三次实际进入模型running并补停，对应唯一NOK；三次模型只消费STOP，START/RUNNING拍数均未增加，没有循环结果，未补造NOK。调试连接关闭后正常独立运行通过。没有发现需要改变停止优先或拧紧判定的依据。

调试器连接方式须特别核实：[SEGGER的XMC4xxx说明](https://kb.segger.com/Infineon_XMC4xxx)明确该型号连接阶段会复位，不能用每次新建连接的RAM读取冒称无侵入观察。现场独立连接预检被CPU暂停门禁拒绝，随后在空闲时建立唯一持久连接、恢复CPU，再在同一会话内savebin；每次读取前后IsHalted均确认运行，测试期间不再connect/reset，结束exit后验证脱离调试器运行。保持原始预检失败证据，不把它归给固件运行故障。
